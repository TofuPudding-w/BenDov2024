# BenDov2024 Algorithm README

本项目是 Ben\-Dov et al\. \(2024\) 论文《Approximate encoding of quantum states using shallow circuits》的复现，实现了量子态的浅层线路近似编码算法，对比了 2020 年的 Ran 基线算法与 2024 年的层间优化算法，能够高效地将高纠缠的量子多体态编码为浅层量子线路，用于量子态的制备与解缠。

## 目录结构

```Plain
BenDov2024/
├── ran2020.py               # 2020年Ran算法的核心实现，提供MPS压缩、MPD构建等基础函数
├── BenDov2024.py            # 2024年Ben-Dov优化算法的核心实现，层间迭代优化器
├── main.py                  # 项目入口脚本，复现论文的核心实验与结果绘图
└── outputs/                 # 实验输出目录，保存复现的论文结果图像
```

本项目提供了灵活的运行模式，可根据需求选择运行：

### 完整复现

运行所有实验，完整复现论文的核心结果：

```bash
python main.py --all
```

### 快速测试

使用更小的参数，快速验证算法的正确性：

```bash

```


## 实验细节

### 算法对比

本项目对比了两种量子态编码算法：

1. **Ran 2020 基线算法**：逐层初始化解缠门，每一层根据当前 MPS 构建解缠门后直接应用，无迭代优化，是 2020 年的经典解缠算法。

2. **Ben\-Dov 2024 优化算法**：在 Ran 算法的基础上，加入了层间交替迭代优化，对每一层的解缠门进行逐步优化，能够在相同的线路层数下，大幅提升编码的保真度。

### 复现的核心实验

本项目复现了论文的三个核心实验：

1. **Ising 模型迭代收敛实验**：测试不同系统大小、不同线路层数下，编码的 infidelity 随迭代次数的变化，同时对比直接截断的理论边界。

2. **XXZ 模型各向异性测试**：测试不同 Jz 各向异性参数下，优化前后的 infidelity 变化，验证算法在不同相互作用模型下的有效性。

3. **层数缩放实验**：测试固定系统大小下，不同线路层数对最终编码保真度的影响，验证浅层线路的编码能力。

## 实验结果

实验结果表明，Ben\-Dov 2024 的优化算法能够：

- 在少量的迭代次数内，将编码的 infidelity 降低几个数量级，大幅提升保真度

- 仅使用浅层的量子线路（最多 6 层），就能够将高纠缠的量子多体态编码为接近乘积态的形式

- 在不同的量子多体模型（Ising、XXZ）下都有稳定的表现，对不同的各向异性参数都有效
